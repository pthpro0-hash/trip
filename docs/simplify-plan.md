# 줄이기 안 (2026-10-14)

일반 사용자에게 앱이 복잡해 보인다는 걱정에서 시작했다. 기능을 네 칸으로 나누고, 사용자가 고른 대로 같은 날 적용했다.

## 왜 복잡했나

- 한 앱에 서비스가 셋이다 — 내 여행 기록 / 여행 100선(관광 안내·지역) / 가족 책장(엽서). 로그인 전 첫 화면은 여행 100선이다.
- 앱이 해야 할 정비가 버튼으로 나와 있었다 — 해외 장소 이름 새로 붙이기, 보관함 정리.
- 같은 것을 보는 길이 여럿이고 이름이 낯설었다 — 내 여행 지도·목록·한장 요약·발자취·여행 상세 지도.
- 숫자: 화면 주소 약 27개, 도움말 59항목.

## 적용한 것

| 칸 | 한 일 |
|---|---|
| 뺐다 | 지도의 '칠한 곳'(다녀온 시도 칠하기·세기), 코스 짜기('이번 여행', /course → 여행 100선), 곳별 방문 화면(/places → 내 여행 지도), 가고 싶은 곳 받기(부모님 → 나, /m/…/wish → 책장 처음), 발자취 재생(한장 요약·링크 화면에서 발자취 칸 삭제, 부모님 화면의 지도는 점이 다 찍힌 지도로) |
| 자동으로 | 해외 장소 이름 — 내 여행을 열 때 거친 이름만 저절로 새로 붙인다(한 번에 20곳, 물어본 곳은 이 기기에서 기억). 내 정보의 '보관함 정리'·'해외 이름 새로 붙이기' 줄은 없앴다(보관함 정리는 도움말 '내 데이터'에 남음) |
| 접었다 | 가족 책장 카드 — 링크 복사만 앞에, 나머지는 '더 보기'. 도움말 — 자주 묻는 10개만 먼저, 나머지는 갈래마다 접기. 사진 고르기 카드의 '다듬기' → '고치기'(나누기·합치기는 이미 접혀 있었다) |
| 그대로 | 지역 보기, 첫 화면(여행 100선), 하단 탭 5개 |

데이터베이스(mailbox_wishes 표·mailbox_wish 함수, 설정의 wish 칸)는 그대로 두었다 — 화면에서만 뺐다. 이미 받은 '가고 싶은 곳' 줄은 표에 남아 있다.

## 다음에 정할 것

- 로그인 전 첫 화면을 여행 100선(관광 안내)으로 둘지, 내 여행 스케치 소개로 바꿀지 — 가족 관찰 결과를 보고.
- 하단 탭 5개 — 쓰인 횟수를 보고.
